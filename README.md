# FG-TIDA Use Cases

This repository holds use case submissions for FG-TIDA, together with the
submission template.

Use cases ground the Focus Group's work in concrete situations: who is acting,
what they are doing, what fails today, and what would have to exist for it to
work. They feed into theme scoping and, in turn, into FG-TIDA's deliverables.

Each submission has its own folder containing the completed template.

## Contributing

- Download the [submission template](./FG-TIDA_UseCase_Template_v1.docx) and
  complete every field.
- The checkboxes are clickable in Word for Mac and Windows. They are not
  clickable in Word for the web.
- Add your completed file as a PR against this repo.
- Folder naming convention: `<sector>-<short-title>/FG-TIDA_UseCase_<short-title>.docx`.
  For example, `smart-home-emergency-access/FG-TIDA_UseCase_emergency-access.docx`.
- Proposal IDs are assigned by the FG secretariat. Once that numbering is in
  place, folders will move to `<proposal-id>-<short-title>`.
- Once a PR is merged, update the index table above with a link to the new file.
